# 知识点深入讲解设计

## 背景

上一轮已完成 03-05 阶段单讲页的助学栏目补齐：每页都有 `作业怎么答`、`卡点急救` 和 `Mini 自检`。这些内容解决了“怎么把知识点写成作业答案”的问题，但仍偏流程化。

新的反馈是：内容方面需要更加深入地讲解。这里的“深入”不等于把所有页面平均写长，而是补上读者真正卡住的三类桥接：

1. **物理直觉桥接**：公式对应什么场景，为什么这一步符合波在结构里传播的图像。
2. **公式来源桥接**：从前一个基础方程到当前常用式之间缺少哪几步。
3. **跟读例子桥接**：用小型判断例子演示如何从概念走到结论。

## 设计目标

让零基础或半理解读者读完页面后，不只是知道“答题顺序”，还应能回答：

- 这个公式为什么长成这样？
- 哪一步来自边界条件，哪一步来自传播条件？
- 这个结论在物理图像上意味着什么？
- 如果题目换一种问法，我该怎样迁移？

## 内容结构

每个页面根据需要新增一个 `## 深入理解` 或更具体的二级标题，例如：

- `## 深入理解：为什么波导多了横截面本征问题`
- `## 深入理解：从 Helmholtz 到 $k_{\mathrm c}$`
- `## 深入理解：相速大于 $c$ 为什么不矛盾`

每个深入块由三部分组成。

### 1. 物理图像

用 1-2 段解释公式背后的图像。写作要求：

- 不重复已有“零基础读前翻译”。
- 不用空泛比喻替代技术含义。
- 每段都要能回到页面里的一个公式、边界条件或题型。

示例方向：

- $k^2=k_{\mathrm c}^2+\beta^2$ 可解释为总波矢被分成横向约束和轴向传播。
- 单模等效长线的前提是只剩一个独立传播通道，因此轴向问题重新变成一维。
- 空心波导无 TEM 的关键是横截面势函数没有非平凡电压差来源。

### 2. 公式桥接

补 2-4 个关键中间步骤，不做教材全文推导。写作要求：

- 只使用页面已有公式和已校验题解口径。
- 标出“这一项来自边界”“这一项来自行波假设”“这一项来自同一模式导行条件”。
- 不新增未经验证的复杂公式。

示例方向：

- 从 $\nabla^2\psi+k^2\psi=0$ 到 $k_x^2+k_y^2+\beta^2=k^2$。
- 从 $\beta=\sqrt{k^2-k_{\mathrm c}^2}$ 到 $\lambda_{\mathrm g}=2\pi/\beta$。
- 从 $\Gamma(z)=\Gamma_L e^{-j2\beta z}$ 到波节间距使用 $\lambda_{\mathrm g}/2$。

### 3. 跟读例子

给一个小型判断例子或反例。写作要求：

- 优先使用已有题解中的口径和数字。
- 例子不追求完整大题计算，重点展示判断路径。
- 结尾写出“这说明什么”，避免只列步骤。

示例方向：

- “若 $\lambda_0$ 接近 $\lambda_{\mathrm c}$，为什么 $\lambda_{\mathrm g}$ 变大？”
- “只给驻波比为什么不能唯一确定负载？”
- “介质填充为什么降低截止频率但不改变几何 $k_{\mathrm c}$？”

## 事实边界

新增深入讲解只允许使用：

1. 当前页面已有公式、定义和图像。
2. 已校验作业解答。
3. `docs/KNOWLEDGE_AUDIT.md`、`docs/QUESTION_AUDIT.md`、`docs/AUDIT_NOTES.md` 中已有反查口径。
4. 必要课程常识，但只能用于解释已出现结论。

不新增教材外数值、不引用未发布课件原文、不引入未在本项目中出现的高级理论。

## 非目标

- 不把 16 页全部平均扩成大章。
- 不新增独立长文替代单讲页。
- 不改 `build.py`、样式、配图脚本或导航结构。
- 不改已经校验过的题解数值口径。

## 验收标准

完成后应满足：

- 8 个目标页面均新增深入讲解块。
- 每个深入块至少包含物理图像、公式桥接或跟读例子中的两类；核心页应三类齐全。
- 新增内容不破坏现有 `作业怎么答`、`卡点急救`、`Mini 自检` 结构。
- 静态构建通过。
- 交叉引用检查缺失为 0。
- `git diff --check` 无格式问题。

验证命令：

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python build.py
python3 scripts/tools/check_cross_refs.py
git diff --check
```
