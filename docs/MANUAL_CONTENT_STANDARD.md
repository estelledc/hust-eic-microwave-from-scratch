# 人工精写内容标准

本文件用于约束后续扩充《微波技术基础》站点内容。目标不是机械增加字数，而是写出零基础大学生能跟读、能做题、能复述的讲义。任何新增内容都必须按本标准人工完成。

## 禁止事项

1. 禁止用生成器、模板循环或批量填充方式制造大段正文。
2. 禁止为了字数重复同一套句式、同一组例子或同一段解释。
3. 禁止没有事实来源地扩展公式、题型或工程结论。
4. 禁止把“看起来通顺”当成合格；每一句都必须能说明它解决了读者的哪一个理解障碍。

## 面向对象

默认读者是刚开始学习《微波技术基础》的大学生。写作时假定读者已经学过基础电路和大学物理电磁学，但还不能自动完成以下动作：

- 把几何长度换成电长度。
- 判断什么时候用集总参数、什么时候用分布参数。
- 分清自由空间波长、介质中波长、导波波长和截止波长。
- 分清阻抗、导纳、归一化量和参考面。
- 看懂公式中的每个字母来自题目、结构、边界、端口还是测量读数。

## 单页结构

每一页至少回答六个问题：

1. **本页在问什么**：用一句不含公式的话说清问题。
2. **为什么要学它**：说明它和后续公式、作业或实验的关系。
3. **物理图像是什么**：用传播、反射、边界、端口或测量图像解释。
4. **公式从哪里来**：不必每次完整推导，但要交代定义、前提和符号来源。
5. **题目怎么写第一步**：给出草稿纸上的判断顺序。
6. **最容易错在哪里**：指出错因，而不是只列“注意事项”。

## 逐句检查

写完一段后，逐句问：

- 这句话是否比前一句提供了新的判断、解释或过渡？
- 这句话是否能被零基础读者用自己的话复述？
- 这句话里的每个术语是否已经解释过，或能从上下文看懂？
- 这句话是否存在“看似专业但没有教学作用”的空话？
- 如果删掉这句话，读者会不会少一个必要理解步骤？

不能回答这些问题的句子应删除或重写。

## 事实来源

优先使用以下来源：

1. 已校验的作业解答和符号导读。
2. 现有知识点页的公式口径。
3. [audit/KNOWLEDGE_AUDIT.md](audit/KNOWLEDGE_AUDIT.md)、[audit/QUESTION_AUDIT.md](audit/QUESTION_AUDIT.md)、[audit/AUDIT_NOTES.md](audit/AUDIT_NOTES.md) 中的反查结论。
4. 已融入课程资料的阶段 README。

不确定的结论必须标注为经验判断、近似条件或课程口径，不得写成绝对定律。

## 扩充节奏

后续扩到更大规模时，按页推进，而不是按字数推进。每次最多处理一到三页，完成后必须做：

- 本页人工通读。
- 对应作业或实验反查。
- `PYTHONDONTWRITEBYTECODE=1 .venv/bin/python build.py`
- `python3 scripts/tools/check_cross_refs.py`
- `git diff --check`

只有通过这些检查，才把该页计入有效扩充。
