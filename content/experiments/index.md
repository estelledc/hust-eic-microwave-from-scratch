## 实验前必读

| 项 | 内容 |
|---|---|
| 仪器 | AV36580 一体化矢量网络分析仪（信号源 + 接收机一体；30 kHz–3 GHz） |
| 端口 | 两个 N 型阴头端口；当前源输出端口由黄色灯指示 |
| 损毁电平 | 射频功率 +26 dBm，DC 电压 ±30 V（千万别接电池或大功率源） |
| 校准 | 实验室通常已做好 SOLT 校准并保存，按 **复位** 调用 |
| 连接 | 接 / 拔射频接头时拧到位即可，不要施加扭矩；电缆别打死结 |

## 报告共同要求

每个实验都要交一份报告，结构统一为：

1. **实验目的、内容、系统简图**
2. **步骤简述 + 仪器关键设置**（频率范围、源功率、扫频点数、平均因子）
3. **数据记录**（频率 + 读数 + 单位）
4. **数据处理**（套公式算 SWR、$|\Gamma|$、$Z_{\mathrm{in}}$、Q、耦合度等）
5. **误差分析**（连接器损耗、读数分辨率、温漂等）
6. **思考题**（每实验末尾分别给出，每题独立成节）
