# 实验环节符号与导读

> 进入实验前统一一遍仪器记号、端口约定和读数单位。

## 一、仪器与端口约定

| 项 | 约定 |
|---|---|
| 仪器型号 | AV36580 一体化矢量网络分析仪（中电四十一所） |
| 频率范围 | 300 kHz – 3 GHz（实验扫频通常落在 100 MHz – 2 GHz） |
| 端口 1 / 2 | 两个 N 型阴头；标号印在面板上；当前源输出端口由黄色灯指示 |
| 端口阻抗 | 标准 $50\,\Omega$ |
| 源功率 | 默认 $0\,\mathrm{dBm}$ 区域；本实验全部用低功率（$-25\sim -10\,\mathrm{dBm}$）以避免器件损坏 |

## 二、负载类型与图标

| 负载 | 标签 | 在屏幕上的史密斯圆图位置 |
|------|------|---------------------------|
| 开路（open）| OPEN | 圆图最右端（$\Gamma=+1$） |
| 短路（short）| SHORT | 圆图最左端（$\Gamma=-1$） |
| 匹配负载（load）| LOAD | 圆图圆心（$\Gamma=0$） |

「校准」需要这三个标准件外加一个直通（thru），合称 SOLT。本实验用的是已经预先校准好的状态。

## 三、单位区分

- **dB**：相对量，比值的对数。例：$|S_{21}|=-3\,\mathrm{dB}$ 表示输出电压幅度是输入的 $10^{-3/20} \approx 0.707$ 倍。
- **dBm**：绝对功率，参考 1 mW。$0\,\mathrm{dBm} = 1\,\mathrm{mW}$；$-10\,\mathrm{dBm} = 0.1\,\mathrm{mW}$。
- **°（度）**：相位单位；屏幕显示通常 $\pm 180°$ 包绕。
- **dB/GHz**：群延迟图上的纵轴单位（极少用）。

## 四、屏幕显示格式速记

| 格式 | 等价物 | 用在哪 |
|------|--------|--------|
| 对数幅度 | $20\log_{10}|S|$ | 看 dB 数 / 找 3 dB 点 |
| 线性幅度 | $|S|$ | 偶尔需要直接做线性运算时 |
| 相位 | $\arg(S)$（度） | 看相位变化 / 群延迟前置 |
| 群延迟 | $-\mathrm{d}\arg(S)/\mathrm{d}\omega$ | 滤波器带内平坦度 |
| 驻波比 | $\rho = (1+|\Gamma|)/(1-|\Gamma|)$ | 直接读 SWR |
| 史密斯圆图 | $\Gamma$ 复平面 | 看阻抗轨迹、判断状态 |
| 极坐标 | $\Gamma$ 极坐标 | 替代史密斯，少用 |

## 五、按键速记

| 按键 | 功能 |
|------|------|
| 复位 | 恢复默认 / 已保存的校准状态（**每个实验第一步**） |
| 起始 / 终止 | 设扫频起止频率（数字键 + 单位键） |
| 中心 / 跨度 | 等价的另一种扫频设置方式 |
| 测量 | 选 $S_{11}/S_{12}/S_{21}/S_{22}$ |
| 格式 | 选屏幕显示格式（见上一节） |
| 平均 | 开/关测量平均（噪声大时用，典型平均因子 8–16） |
| 光标 | 显示光标，旋钮调位置；△光标做相对读数 |
| 搜索 | 自动找最大/最小值；带宽搜索给出 $f_0$、BW、Q |
| 通道 / 显示 | 控制窗口、轨迹分布 |
| 校准 | 启动 SOLT 校准（实验中通常已预存） |

## 六、思考题答题约定

- 每题独立小节，标题标 **思考题 N**
- 先**复述题目**（避免误读）
- 再**画图或列公式**（不能只写一句结论）
- 最后**给单位齐全的答案**
