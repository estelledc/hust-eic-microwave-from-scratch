# 实验二 · 微波元件特性参数测量

> 一台 VNA、三组测量、三类元件。

## 一、实验目的

1. 掌握利用 VNA 扫频测量微带谐振器 Q 值的方法
2. 学会使用 VNA 测量微波定向耦合器的特性参数
3. 掌握使用 VNA 测试微波功率分配器传输特性的方法
