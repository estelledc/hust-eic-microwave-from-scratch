# 实验一 · 矢量网络分析仪与传输线测量

> 学一台仪器、做两组测量、读懂三种工作状态。

## 一、实验目的

1. 学习矢量网络分析仪的基本工作原理
2. 初步掌握 AV36580 的操作使用方法
3. 掌握使用 VNA 测量微带传输线在不同工作状态下的 S 参数
4. 通过测量认知 $\lambda/4$ 传输线阻抗变换特性
