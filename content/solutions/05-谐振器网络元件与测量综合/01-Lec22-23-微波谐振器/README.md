## 本模块先抓住

- 谐振腔 = 波导/传输线 + 两端边界。
- 矩形腔 $\mathrm{TE}_{101}$：$f=\frac{c}{2}\sqrt{1/a^2+1/l^2}$。
- 圆柱腔 TE 用 $\chi'_{mn}$，TM 用 $\chi_{mn}$。
- $Q_0$ 推导路径是“场分布 → 储能 → 壁面损耗”，不是孤立背公式。
