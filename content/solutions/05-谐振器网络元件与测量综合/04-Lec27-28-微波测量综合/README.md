## 本模块先抓住

- \(S\) 参数 dB 用 \(20\log\)，功率比 dB 用 \(10\log\)。
- Smith 圆图上的点是反射系数，不是阻抗本身；阻抗是由反射系数换算得到。
- 多端口测量未测端口必须接 \(50\,\Omega\) 匹配负载。
