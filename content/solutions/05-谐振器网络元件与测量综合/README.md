## 阅读建议

- **先看符号导读**：本次题目端口、参考面、负载反射系数较多，符号错位会直接导致答案错。
- **网络题从定义式推**：不要背结论。先写 $b_1=S_{11}a_1+S_{12}a_2$、$b_2=S_{21}a_1+S_{22}a_2$，再代入负载条件。
- **测量题先分清幅度比/功率比**：$S$ 参数 dB 用 $20\log$；功率比用 $10\log$。
- **多端口题先画端口**：耦合度、隔离度、方向性的下标随端口定义变化。
