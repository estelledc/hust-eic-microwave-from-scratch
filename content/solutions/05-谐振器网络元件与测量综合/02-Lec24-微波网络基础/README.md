## 本模块先抓住

- \(S_{ij}\) 的第一个下标是出射端口，第二个下标是入射端口。
- 其他端口接匹配负载时，才可直接把测量值称为某个 \(S_{ij}\)。
- 接负载二端口的输入反射系数来自 \(a_2=\Gamma_L b_2\)。
