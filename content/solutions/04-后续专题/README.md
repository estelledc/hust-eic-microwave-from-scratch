- 圆波导半径 \(R\)；同轴线内导体外半径 \(a\)、外导体内半径 \(b\)（\(a<b\)）。

- 空气圆波导截止：\(f_{\mathrm c,\mathrm{TM}_{mn}}=c\chi_{mn}/(2\pi R)\)、\(f_{\mathrm c,\mathrm{TE}_{mn}}=c\chi'_{mn}/(2\pi R)\)。

## 阅读建议

- **先看知识点再做题**：每题"对应知识点"列在题首，可点回 [knowledge/06](../../knowledge/06-圆波导同轴线微带线/README.md) 中对应一节。
- **模式枚举类题**：先算 \(kR\) 或 \(\lambda_0\) 与各 \(\chi\) 比较；圆波导主模 \(\mathrm{TE}_{11}\) 不要漏极化简并。
- **介质填充类题**：保持 \(f_{\mathrm c}\) 不变要把几何尺寸按 \(1/\sqrt{\varepsilon_r}\) 同步缩小。
- **同轴/微带 TEM 类题**：判清"严格 TEM"还是"准 TEM"——同轴均匀填充可严格 TEM，微带半填充只能准 TEM。
