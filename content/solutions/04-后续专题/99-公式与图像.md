## 圆波导公式卡

| 量 | 公式 |
|----|------|
| 截止波数（TM） | \(k_{\mathrm c}=\chi_{mn}/R\) |
| 截止波数（TE） | \(k_{\mathrm c}=\chi'_{mn}/R\) |
| 空气截止频率 | \(f_{\mathrm c}=c\,k_{\mathrm c}/(2\pi)\) |
| 介质截止频率 | \(f'_{\mathrm c}=f_{\mathrm c}/\sqrt{\varepsilon_r}\) |
| 保 \(f_{\mathrm c}\) 不变的半径缩放 | \(R'=R/\sqrt{\varepsilon_r}\) |
| 单模窗口 | \(\chi'_{11}/R<k<\chi_{01}/R\) |

低阶根速查（必背）：

```
χ'_11 = 1.841    (TE11, 主模)
χ_01  = 2.405    (TM01, 第二模)
χ'_21 = 3.054    (TE21)
χ'_01 = 3.832    (TE01)
χ_11  = 3.832    (TM11, 与 TE01 简并)
```

模枚举套路：算 \(kR=2\pi R/\lambda_0\)，与各根逐个比较。
