## 公式使用前提总表（速记版）

摘自 [知识点总览 · 公式前提](../../knowledge/README.md#公式使用前提总表)：

| 公式类型 | 先确认什么 | 典型错误 |
|----------|------------|----------|
| 传输线输入阻抗 | 无耗/有耗；线长从哪量 | 坐标反了；开短路符号反了 |
| Smith 圆图 | 是否归一化；看 $Z$ 还是 $Y$ | 并联题还在加阻抗 |
| 波导截止 | 模式合法；比 $f$ 还是 $\lambda$ | $\lambda_0<\lambda_c$ 写反 |
| 导波波长 | 已确认 $f>f_c$ | 截止以下仍算 $\lambda_g$ |
| 谐振器 Q | $Q_L$ 还是 $Q_0$ | 有载 Q 当无载 Q |
| S 参数 dB | 波幅比 | 对 $S_{ij}$ 用了 $10\log$ |
