# 学习指南

这里放面向初学者的学习路线和使用方法。第一次打开站点时，建议先读入门手册，再按知识点、作业和实验三条线交叉复习。

## 推荐入口

| 入口 | 适合解决什么问题 |
|---|---|
| [阅读地图](reading-map.md) | 十轮读法、任务入口表、十分钟定位法与详细导读 |
| [零基础学习手册](beginner-handbook.md) | 不知道先看哪一章、公式太多、题目和实验衔接不上 |
| [知识点总览](../knowledge/README.md) | 建立传输线、波导、谐振器、网络和测量的主线 |
| [作业解答总览](../solutions/index.md) | 按讲次做题、查标准流程和常见误区 |
| [实验环节总览](../experiments/index.md) | 把 VNA 读数写成报告里的物理结论 |

## 使用顺序

1. 先读 [零基础学习手册](beginner-handbook.md)，明确全课程路线。
2. 每学一章，先看知识点总览，再看对应作业。
3. 遇到仪器截图或实验报告，回到实验环节按“读数 → 换算 → 结论 → 误差来源”写。
4. 考前用各阶段 `99` 自检清单查漏，不要只背公式表。
