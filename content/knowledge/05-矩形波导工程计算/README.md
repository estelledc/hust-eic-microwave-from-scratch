`矩形波导1.pdf` 的工程题部分已融入本阶段。遇到尺寸和频率题，按下面四步写草稿：

1. 列出候选 $\mathrm{TE}_{mn}$ / $\mathrm{TM}_{mn}$，先排除非法下标。
2. 对每个模算 $\lambda_{\mathrm c}$ 或 $f_{\mathrm c}$，按门槛排序。
3. 用工作频率判断“截止、单模、多模”，必要时给出单模窗口。
4. 已确认单模后，才把长线里的 $\Gamma$、$\rho$、匹配语言接到波导段上。

## 本阶段做题怎么上手

矩形波导工程题不要从 $\lambda_{\mathrm g}$ 或 $\Gamma$ 公式开始。先在草稿纸上完成五个判断：

| 判断 | 先问自己 | 答题落点 |
|------|----------|----------|
| 几何与频率 | 给了 $a,b$ 和 $f$ 还是 $\lambda_0$ | 统一成可比较的 $\lambda_{\mathrm c}$ 与 $\lambda_0$（或 $k$ 与 $k_{\mathrm c}$） |
| 模是否合法 | TE/TM 下标能否代入 | 非法项不进表；TM 常要 $m,n\ge1$ |
| 哪些模可传 | 每个 $\lambda_{\mathrm c}$ 与 $\lambda_0$ 比较 | 枚举题列全；截止则停 |
| 是否单模 | 除 $\mathrm{TE}_{10}$ 外高次模是否仍截止 | 单模才进 $\lambda_{\mathrm g}$、阻抗、匹配 |
| 问的是轴向量还是截面量 | 波节、螺钉、匹配 vs 模谱、截止 | 轴向上只用 $\lambda_{\mathrm g}$；门槛用 $\lambda_{\mathrm c}$ |

第一次读目录建议：先扫 [00](00-工程计算路线图.md) 的模式门禁四格和本表，再按 01→04 做模谱与枚举，最后读 [05](05-波导段反射驻波与匹配.md) 接长线理论。
