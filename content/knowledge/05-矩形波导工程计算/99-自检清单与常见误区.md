# 06 · 自检清单与常见误区（Lec13–Lec16）

---

![单模波导段的驻波、导波波长与匹配自检](../../../assets/images/gpt-wg-standing-wave-matching-lambdag.webp)

*图：确认只有主模后，波导段可借用传输线工具；但驻波距离、螺钉位置和匹配电长度都要用 $\lambda_{\mathrm g}$。*

## 这页怎么用

Lec13–16 综合题做完后，用本页逐项反查。自检不是背 $k_{\mathrm c}$ 公式，而是确认你是否真的过了“模式门禁”。

每道题至少过四关：

1. **候选模合法吗**：TM 下标、TE 下标是否先筛过？
2. **门槛算对了吗**：$\lambda_{\mathrm c}$ 是否只由 $a,b,(m,n)$ 决定？
3. **单模前提写了吗**：高次模是否全部核对，而不只写 $a<\lambda_0<2a$？
4. **轴向量用对尺子了吗**：波节、螺钉、匹配是否都用 $\lambda_{\mathrm g}$？

有一关答不清，先回 [00-工程计算路线图](00-工程计算路线图.md) 重画四格门禁，不要继续硬算反射或功率。

---

## 草稿纸上怎么串 Lec13–16

考前可在草稿顶部固定这条链，子题都挂在其上：

```
a,b + f或λ0 → 列合法 TE/TM → 算各 λc
         ↓
    筛可传模（λc > λ0）
         ↓
    单模？多模？枚举？
         ↓ 单模 TE10
    λg, vp, vg → Γ, ρ, 波节 → 匹配
```

闭卷复盘三问：

1. 这题是在枚举模，还是在单模下算传播参数或反射？
2. 介质填充改的是 $k$ 还是几何 $k_{\mathrm c}$？
3. 沿波导量的长度，用的是 $\lambda_{\mathrm g}$ 还是 $\lambda_0$？

---

## 考前速查清单

- [ ] **$k_{\mathrm c}$、$\lambda_{\mathrm c}$、$f_{\mathrm c}$** 公式；$\mathrm{TM}$ 的 $m,n\ge 1$；**$\mathrm{TE}_{11}$/$\mathrm{TM}_{11}$** 简并（$k_{\mathrm c}$ 同）。
- [ ] 导行：空气中 **$\lambda_0<\lambda_{\mathrm c}$**（或 $f>f_{\mathrm c}$）；介质填充优先比较 $k>k_{\mathrm c}$。
- [ ] **只传 $\mathrm{TE}_{10}$**：$\lambda_0<2a$ 且所有相关高次模不导行；注意 **$a>2b$** 的常见标准波导先看 **$\mathrm{TE}_{20}$**。
- [ ] **$\varepsilon_{\mathrm r}$ 全填充**：$k_{\mathrm c}$ 和几何 $\lambda_{\mathrm c}=2\pi/k_{\mathrm c}$ 不变，$f_{\mathrm c,\,\varepsilon}=f_{\mathrm c,\,air}/\sqrt{\varepsilon_{\mathrm r}}$；若用自由空间 $\lambda_0$ 比较，门槛乘 $\sqrt{\varepsilon_{\mathrm r}}$。
- [ ] **$\lambda_{\mathrm g}$、$v_{\mathrm p}$、$v_{\mathrm g}$** 与 **$f_{\mathrm c,10}/f$**；无耗空气中验算 **$v_{\mathrm p}v_{\mathrm g}=c^2$**。
- [ ] **枚举模**：$\lambda_{\mathrm c}>\lambda_0$ 列表；大截面注意 **截断**。
- [ ] **驻波**：相邻电场波节 **$\lambda_{\mathrm g}/2$**；螺钉距离用 **$\lambda_{\mathrm g}$** 电长度；对齐 **第二次作业 $\Gamma(z)$** 约定。
- [ ] **第 12 题功率**：用教材 **$P_{\mathrm{max}}$** 与 **$E_{\mathrm{br}}$**（峰值/有效值）及 **$Z_{\mathrm{TE}}$** 的**指定系数**计算，勿抄网络常数。

## 常见误区（简表）

| 误区 | 正解提要 |
|------|----------|
| 轴向几何长度用 $\lambda_0$ 代 $\lambda_{\mathrm g}$ | 波导内相位常数为 $\beta=2\pi/\lambda_{\mathrm g}$。 |
| 单模条件只写 $a<\lambda_0<2a$ | 必须核对 **$\mathrm{TE}_{01}$、$\mathrm{TE}_{11}$** 等是否给出更紧的 $\lambda_0$ 下界。 |
| 介质填充只改 $\mathrm{TE}_{10}$ 的 $f_{\mathrm c}$ | **所有模**的 $f_{\mathrm c}$ 都会降低；几何 $k_{\mathrm c}$ 不变。 |
| 多模题目仍用单模 $Z_{\mathrm{TE}}$ 乱套 | 先判模；模式耦合题超出基础假设时以题设为准。 |

## 功率容量（第 12 题 · 审题清单）

1. 确认教材中 **$\mathrm{TE}_{10}$** 的 **$Z_{\mathrm{TE}}$** 与 **场强峰值位置**。
2. 确认 **$E_{\mathrm{br}}$** 是峰值还是有效值，与公式配套。
3. 数值只做**量级核对**（解答给出约 **0.8–1.0 MW** 量级），答卷以教材公式为准。

## 考前口述题参考答案

1. **矩形波导工程题第一步是什么？**
   先列候选模并计算每个模的 $k_{\mathrm c}$、$\lambda_{\mathrm c}$ 或 $f_{\mathrm c}$，判断哪些模能导行。只有确认单模 $\mathrm{TE}_{10}$ 后，才进入等效传输线、反射和匹配计算。

2. **为什么 $\mathrm{TE}_{10}$ 是主模？**
   对常见 $a>b$ 的矩形波导，$\mathrm{TE}_{10}$ 的 $k_{\mathrm c}=\pi/a$ 最小，等价地 $\lambda_{\mathrm c}=2a$ 最大，因此最先达到导行条件。

3. **单模工作区怎么说清楚？**
   主模要能传，即空气中 $\lambda_0<2a$；所有相关高次模要不能传，即 $\lambda_0$ 不小于这些高次模的 $\lambda_{\mathrm c}$。不能只背 $a<\lambda_0<2a$，还要检查 $\mathrm{TE}_{01}$、$\mathrm{TE}_{11}$ 等是否更严格。

4. **介质填充时什么变、什么不变？**
   几何 $k_{\mathrm c}$ 和几何 $\lambda_{\mathrm c}$ 不变；介质中的 $k=\omega\sqrt{\mu\varepsilon}$ 变大，所以各模截止频率降低。若用自由空间 $\lambda_0$ 比较，门槛要乘 $\sqrt{\varepsilon_{\mathrm r}}$。

5. **波导段反射匹配为什么要回到长线理论？**
   单模波导沿轴向可等效成一根具有相位常数 $\beta$ 和特性阻抗的传输线，所以 $\Gamma$、$\rho$、波节位置、匹配网络仍然适用。但距离和电长度必须用 $\lambda_{\mathrm g}$，并且坐标方向要和题解约定一致。

## 零基础卡点急救

第五阶段的题型容易在“先判模还是先套公式”上出错。卡住时按这个表回跳：

| 卡点 | 先回看 | 先问自己 |
|------|--------|----------|
| 不知道从哪开始算 | [00-工程计算路线图](00-工程计算路线图.md) | 我是否已经先列模、算截止、判单模？ |
| 主模和简并混乱 | [01-模谱主模与简并](01-模谱主模与简并.md) | $k_{\mathrm c}$ 最小的是谁？简并是否只表示截止相同？ |
| 单模窗口不会列不等式 | [02-单模工作区与介质填充](02-单模工作区与介质填充.md) | 主模是否能传？高次模是否都被关住？ |
| $\lambda_{\mathrm g}$、相速、群速算乱 | [03-导波波长相速群速算例](03-导波波长相速群速算例.md) | 我是否已确认单模，并使用 $\lambda_{\mathrm g}=2\pi/\beta$？ |
| 可传输模枚举漏模 | [04-可传输模判定与枚举](04-可传输模判定与枚举.md) | TE 和 TM 是否分开列？$\lambda_{\mathrm c}>\lambda_0$ 的都列了吗？ |
| 驻波/螺钉距离用错波长 | [05-波导段反射驻波与匹配](05-波导段反射驻波与匹配.md) | 这是沿波导轴向的电长度吗？如果是，应使用 $\lambda_{\mathrm g}$。 |

一个实用顺序：先判可传模；若多模，不要直接套单模传输线；若单模，再用 $\lambda_{\mathrm g}$ 换算轴向电长度，并把第二阶段的 $\Gamma$、$\rho$、Smith 圆图或解析式接回来。

## 工程数值合理性检查

矩形波导题做完后，用这张表快速验算结果是否像真答案：

| 结果 | 合理范围或方向 | 若不满足，优先检查 |
|------|----------------|--------------------|
| $\lambda_{\mathrm g}$ | 导行时 $\lambda_{\mathrm g}>\lambda_0$ | 是否把根号里的 $1-(\lambda_0/\lambda_c)^2$ 写反 |
| $v_{\mathrm p}$ | 非 TEM 波导中常有 $v_{\mathrm p}>c$，但不传信息 | 是否把相速当成群速 |
| $v_{\mathrm g}$ | 无耗空气波导中 $v_{\mathrm g}<c$，且 $v_{\mathrm p}v_{\mathrm g}=c^2$ | 是否漏掉截止项 |
| 单模窗口 | 主模能传，高次模都截止 | 是否只检查了 $\mathrm{TE}_{20}$，漏了 $\mathrm{TE}_{01}$ 或 $\mathrm{TE}_{11}$ |
| 介质填充后 $f_c$ | 均匀介质填充会让截止频率降低 | 是否把尺寸或频率缩放方向写反 |
| 驻波距离 | 相邻波节间距用 $\lambda_{\mathrm g}/2$ | 是否误用自由空间 $\lambda_0$ |

一句话检查：只要题目已经进入波导内部的轴向距离、相位或驻波，就优先问“这里该不该用 $\lambda_{\mathrm g}$”。
