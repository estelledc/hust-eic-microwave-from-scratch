## 零基础总路线

这一阶段是全课收束，不要把新名词拆散背。所有题都可以按同一条线问：

1. **结构内部发生什么**：是储能形成谐振，还是波在端口间传输？
2. **端口上能观察什么**：反射、传输、相位、带宽、隔离度还是驻波比？
3. **用哪个参数描述**：谐振器用 $f_0,Q$；二端口和多端口用 $S$ 参数；测量题用 VNA 读数。
4. **理想值和实测值差在哪里**：损耗、端口失配、耦合强弱、校准面和负载都会造成偏差。

做综合题时先画两个图：一个是结构图，标出尺寸和模式；另一个是端口图，标出输入端、输出端、匹配负载和测量量。图画清楚后，公式通常就只是在表达这两张图。

## 本阶段主线

```mermaid
flowchart LR
  A["传输线/波导场"] --> B["两端边界"]
  B --> C["谐振器"]
  C --> D["等效电路与 Q"]
  D --> E["二端口/多端口网络"]
  E --> F["S 参数"]
  F --> G["常用微波元件"]
  G --> H["VNA 测量与报告"]
```

这条线的核心是：不要把谐振器、网络、元件、仪器当成四件孤立的事。它们都在描述同一组量：端口上的入射波、反射波、传输波，以及结构内部怎样储能和损耗。

## 学完这一阶段后

你应该能做到：

1. 看到“谐振腔”题，先写出横向截止项和轴向驻波项，再用 $k^2=k_c^2+k_z^2$ 求谐振频率。
2. 看到“二端口网络”题，能从 $b_1=S_{11}a_1+S_{12}a_2$、$b_2=S_{21}a_1+S_{22}a_2$ 出发处理负载反射。
3. 看到“耦合度/方向性/隔离度”，先确认端口定义，再把 dB 读数转成正值指标。
4. 看到 VNA 屏幕读数，能说明它对应的是功率比、电压波幅比、反射系数还是驻波比。

下一步可回到 [实验环节](../../experiments/index.md)，把本阶段公式落实到实验报告。
