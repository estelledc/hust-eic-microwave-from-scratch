# 《微波技术基础》知识点讲义目录

知识点讲义按第一性原理路线整理：先问“电磁波沿结构如何传播”，再问“遇到不连续为什么反射、怎样匹配”，最后进入“金属边界如何筛选波型、截止和色散如何出现、矩形波导怎么做工程计算”。每个阶段先读总览，再读单讲，最后用自检清单查漏。

![微波学习从传输线到波导的主线](../../assets/images/gpt-long-vs-short-line.webp)

这张图先把“为什么普通导线思维不够用”摆出来：当线长和波长可比，电压电流就沿线变化；再往后，波导只是把这种“沿结构传播”的问题换成了有金属边界的三维版本。
